«Infrastructure as Code implementation for provisioning and managing AWS compute infrastructure with Terraform.»

This project demonstrates the design and implementation of an automated AWS infrastructure workflow using Terraform, Amazon EC2, AWS security groups, Terraform data sources, and Terraform state management.

The implementation covers infrastructure definition, dynamic AMI discovery, secure SSH access configuration, Terraform initialization and validation, execution planning, infrastructure provisioning, state reconciliation, AWS CLI verification, and EC2 lifecycle management.

Core focus: Infrastructure as Code · Terraform · AWS · Amazon EC2 · AMI Discovery · Security Groups · State Management · Infrastructure Automation
